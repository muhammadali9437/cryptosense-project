% ======================================================= ix. abstract
\begin{center}{\Large\bfseries Abstract}\end{center}
\vspace{0.2cm}
{\setstretch{1.6}
CryptoSense AI is a software platform for cryptocurrency market observation and decision support. Its Flutter web interface communicates with a Python FastAPI backend. Backend services collect market information from Binance and from news, sentiment and market-mood providers; engineer time-aligned indicators; produce directional signals with an XGBoost and LightGBM ensemble and transparent seven-factor risk scores; and persist user portfolios, alerts, observed liquidations and simulated practice-trading activity in SQLite or PostgreSQL. The application also provides news, whale-flow, crypto-linked stock trades and listing discovery, educational lessons, a liquidation intelligence dashboard, and Sage, a Risk Copilot that combines six specialist analysts, retrieval-augmented answers and an optional language model whose numbers are checked against computed facts. The application never shows made-up data: when a live input is missing it says so. It does not send real exchange orders and does not provide guaranteed investment predictions.

This updated edition documents the architecture, requirements, data model, API surface, key algorithms, machine learning evaluation, deployment, limitations and a source-derived class and method catalog, and it records what was added, changed and removed since the previous edition. Diagrams include architecture, use cases, activity, signal-generation flowchart, class, sequence, state, paper-trading activity, entity relationship, machine learning pipeline and deployment views. The automated backend test suite (65 tests) was executed and passed. Model results include a majority baseline and a comparison of two, five and ten years of training history; directional prediction remains uncertain, while downside risk proved more predictable than direction.\par}
